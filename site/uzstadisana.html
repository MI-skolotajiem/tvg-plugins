Kas ir spraudnis un kāpēc tas noder?

Spraudnis ir papildinājumu komplekts Codex lietotnei. TVĢ spraudnis pievieno skolotājam sagatavotas darba lapu, diferenciācijas un prezentāciju instrukcijas. Tās palīdz veidot materiālus pēc vienotiem metodiskajiem principiem. Pēc vienreizējas uzstādīšanas instrukcijas nav jākopē katrā jaunā sarunā; uzstādītais Windows uzdevums regulāri saņem autora labojumus. Jūs joprojām norādāt klasi, tematu un savu uzdevumu un izvērtējat sagatavoto materiālu.

Palīdzība pēc lejupielādes: kopēt uzstādīšanas uzdevumu Codex

Ļaujiet Codex palīdzēt ar uzstādīšanu

Nospiediet “Kopēt uzstādīšanas uzdevumu”, atveriet Codex sarunu ar piekļuvi datora failiem un ielīmējiet tekstu. Codex var atrast lejupielādēto failu, izlasīt skriptu un mēģināt veikt uzstādīšanu. Ja būs vajadzīgas atļaujas, lietotne tās pieprasīs.

Parastais ChatGPT pārlūkā nevar palaist failu jūsu datorā. Prompts pats par sevi neko neinstalē. Ja lokālā piekļuve ir bloķēta, izpakotajā mapē atveriet install-tvg.cmd pats.

Četri vienkārši soļi

  1. Uzstādiet Codex un pieslēdzieties. Izmantojiet oficiālo Codex lietotnes lapu. Šis uzstādītājs paredzēts Windows datoriem.
  2. Lejupielādējiet un izpakojiet ZIP. Windows failu pārlūkā izvēlieties “Izvilkt visu” (“Extract All”).
  3. Izpakotajā mapē atveriet install-tvg.cmd. Sagaidiet tekstu “Automatiska parbaude ieslegta” un “TVG uzstadisana pabeigta”. Ja saņemat kļūdu, atjaunināšana nav pilnībā konfigurēta.
  4. Atveriet jaunu Codex sarunu. Ja prasmes vēl nav redzamas, pārstartējiet lietotni. Piemērs: “Izveido darba lapu 7. klasei par fotosintēzi 40 minūtēm.”
Lejupielādēt TVĢ spraudni

Kā notiek atjaunināšana?

Uzstādītājs izveido Windows fona uzdevumu. Tas reizi dienā plkst. 12.00 pēc datora laika pārbauda un instalē jaunās publicētās versijas no TVĢ repozitorija. Datoram jābūt ieslēgtam, lietotājam pierakstītam Windows un pieejamam internetam. Ja dators tajā laikā nav pieejams, uzdevums var izpildīties vēlāk. Jaunu instrukciju lietošanai atveriet jaunu Codex sarunu vai pārstartējiet lietotni.

Kā pārliecināties, ka viss darbojas?

Codex prasmju sarakstā meklējiet TVĢ darba lapas, diferenciāciju un prezentāciju veidošanu. Windows programmā “Uzdevumu plānotājs” (“Task Scheduler”) meklējiet TVG-Codex-Update. Pēc pirmās atjauninājumu pārbaudes failā %USERPROFILE%\.codex\tvg-update\last-update.txt būs rezultāts OK un pārbaudes laiks, vai kļūdas apraksts.

Ja uzstādīšana neizdodas

Ja Codex nav atrasts, uzstādiet to un mēģiniet vēlreiz. Ja skolas datora politika bloķē skriptus vai Windows fona uzdevuma izveidi, lūdziet skolas IT palīdzību. Pats spraudnis var būt uzstādīts arī tad, ja fona uzdevums nav izveidots. Šajā izpildvidē fona uzdevuma reģistrēšana bija bloķēta, tāpēc tā darbība vēl jāapstiprina parastā lietotāja Windows datorā.

Manuāla atjaunināšana un noņemšana

Windows PowerShell atjaunināšanai:

codex plugin marketplace upgrade tvg-skolotajiem
codex plugin add tvg@tvg-skolotajiem

Noņemšanai:

Unregister-ScheduledTask -TaskName TVG-Codex-Update -Confirm:$false -ErrorAction SilentlyContinue
codex plugin remove tvg@tvg-skolotajiem
codex plugin marketplace remove tvg-skolotajiem

Parastajai ChatGPT pārlūka sarunai vai citai lokālai MI programmai šis uzstādītājs nav paredzēts. ChatGPT lietotāji atsevišķās instrukcijas var kopēt no prasmju kataloga.
